# eSLSH

## Concept

Somaliland's shilling is cash-only in practice: high denominations, thick bundles,
and a mobile money market that quietly runs on US dollars. eSLSH puts the shilling
itself on-chain — one token, one shilling, held in reserve and redeemable for paper
cash at any agent.

The app is built around three facts about how money already moves there. A phone
number is an address, so there is no seed phrase to write down. Cash is the exit,
so every flow ends at an agent who can pay out shillings. And trust is earned with
numbers, not marketing, so the reserve ratio, the attestation age and each trader's
completed-trade count sit on screen where people can see them.

Four users share the same wallet: residents sending money across Hargeisa, diaspora
sending remittances home in USDT, merchants charging customers by QR, and traders
working the P2P shilling/USDT market.
